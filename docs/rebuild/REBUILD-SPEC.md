# Rebuild specification

The site must present the current public EMX product catalog through a premium dark UI with restrained purple and green accents, responsive keyboard-accessible navigation, real product imagery, honest product claims, and clear checkout/support paths.

Every public tab must have a complete loading or content state, consistent header/footer, mobile navigation, metadata, and a recovery path when a live API is unavailable. Browser pages must never pretend to inspect hardware they cannot access.

The affiliate system must be owned by EMX: first-party signup/login, approval, referral code, 30-day attribution, deduplicated click totals, confirmed conversion/refund records, configurable rates, commission ledger, and manually recorded payouts. It must not require a paid affiliate SaaS or Payhip affiliate account. Payhip remains only the current payment checkout and signed completed-sale/refund event source.
