How EMX keys work

  • Keys are machine-bound to the PC you activate on.
  • Reinstalling Windows, a factory reset, or a hardware change can void a key.
  • Keep your checkout email + transaction ID for paid products.
  • Keys are not recovered or re-issued for free — see License & Keys.

FREE · WINDOWS

EMX Clips

  1. Download and run the installer from the Clips site.
  2. Open EMX Clips → Settings → Copy Machine ID (24 characters).
  3. Paste your Machine ID into the activation form to get your free, one-PC key.
  4. Enter the key in the app — arm replay and hit your hotkey to save clips.

COMMON FIXES

Stuck? Start here.

The questions we get most, answered fast.

I need to recover my key

Use Claim Key and enter the exact checkout email plus the transaction ID from your receipt. It returns only the products attached to that order. Note: after an OS reinstall, factory reset, or hardware change, a key may be invalid and a new one requires a new purchase (Refund Policy).

Windows shows an "unknown publisher" warning

An installer that isn't code-signed can trigger Microsoft Defender SmartScreen. This is expected for some EMX builds — use the official download links only, and verify a checksum when one is provided.

Will a tweak guarantee more FPS or lower ping?

No. Results depend on your hardware, drivers, Windows state, game settings, network, thermals, and background load. EMX describes what a change does and how to reverse it — it doesn't promise a number.

Where do I get updates?

Use the Updates page and the release link named on each product page. Availability differs by product.

What should I send support?

Send the product name/version, your Windows version, what you clicked, the exact error, and any log the app offers. Mask keys, emails, receipt IDs, and machine IDs in public channels.
