An EMX Original

Game info

PROJECT EMX is an EMX original built on OG movement and modern assets, heading for a Battle Royale with Build and Zero Build.

What is in the open beta on Roblox today is the core that everything else is built on: build, edit and box fighting. Piece control drills against bots, 1v1 maps made by players, your own map maker, and EMX Bucks earned from real eliminations that unlock skins, pickaxes and effects as you level up. The full Battle Royale match is not in the build yet, so this page keeps what you can play today apart from what is still being made. Nothing below is a promise with a date attached to it.

What we are building

The shape of the game. Which of these is in the build you load changes week to week during the beta — the Discord announcements say what is in each build.

  • Build Mode

    Building and editing as the core of a fight: ramps, walls, edits and piece control, with the responsiveness the OG era was built on.

  • Zero Build

    The same movement and gunplay with no building at all — cover, positioning and aim decide the fight.

  • Squads

    Drop in with friends rather than alone, with the squad sizes a Battle Royale expects.

  • Competitive

    Structured play for people who want a scoreline: ranked ladders, tournaments and events run out of the Discord server.

  • Live Events

    Scheduled moments that happen once, announced ahead of time in Discord and on the News page.

  • OG movement, modern assets

    The feel is the point: movement tuned to the original era, dressed in current visuals rather than nostalgia for its own sake.
